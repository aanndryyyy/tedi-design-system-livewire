> **Port note — not implemented here.** In Angular, typed input is normalized on blur to the canonical `HH:mm` form (`9:5` → `09:05`, `1155` → `11:55`, `930` → `09:30`, and any non-digit treated as the separator). That is JavaScript behaviour on the component instance; this package is a template-only port (CONVENTIONS.md §8) and ships no equivalent.
