The expand toggle is moved to the **last column** via `controlColumnOrder`. By default control columns (drag / select / expand) render leading, before the data. Insert the `'content'` sentinel to mark where the data columns sit — any control listed after it renders trailing. Here `['content', 'expand']` keeps the data columns first and pushes the expand toggle to the end; e.g. `['select', 'content', 'expand']` would keep the checkbox leading while trailing the toggle.
